# Баланс — калькулятор ИМТ

Простое приложение на HTML, CSS и JavaScript. Работает без установки библиотек, сервера и подключения к интернету. История расчётов и тема сохраняются в localStorage — небольшом хранилище вашего браузера. Данные никуда не отправляются. Только ссылка на источник открывает внешний сайт.

## Запуск на Windows 10

1. Откройте текущую папку `BMI-Calculator` в Проводнике.
2. Дважды нажмите на файл `index.html`. Приложение откроется в браузере.
3. Если Windows спрашивает, чем открыть файл, выберите Microsoft Edge, Google Chrome или Firefox. Можно нажать правой кнопкой → «Открыть с помощью».
4. Введите рост в сантиметрах и вес в килограммах, затем нажмите «Рассчитать ИМТ». Например: рост 170, вес 65 → ИМТ **22,49**, нормальная масса тела.

Для запуска не нужны Node.js, Python или команды в терминале. После изменений в файлах сохраните их и обновите страницу клавишей F5. Если расширения скрыты, включите в Проводнике «Вид» → «Расширения имён файлов».

## Назначение файлов

- `index.html` — содержимое и структура страницы: заголовки, поля, кнопки, результат и шкала. Это вход в приложение.
- `styles.css` — внешний вид: цвета, шрифты, расположение блоков и адаптация к экрану телефона.
- `script.js` — поведение: проверка полей, вычисление ИМТ, выбор категории и перемещение указателя шкалы.
- `dashboard.js` — новые функции: переключение темы, работа с localStorage, история, удаление записей и интерактивный SVG-график.
- `tests.js` — автоматическая проверка формулы, границ категорий, ошибочного ввода, истории и координат графика. В браузере этот файл не подключается.
- `tests-contrast.js` — проверка контрастности цветов обеих тем по формуле WCAG и защита от повторения ошибки с цветом заголовков. Запускается также из `tests.js`.
- `README.md` — эта инструкция.
- `server.cjs` — необязательный локальный HTTP-сервер на встроенных модулях Node.js; раздаёт файлы калькулятора на порту 8000.

## Запуск через HTTP на порту 8000

В PowerShell, открытом в папке проекта, выполните:

```powershell
$nodePath = Join-Path $env:USERPROFILE '.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe'
& $nodePath .\server.cjs
```

Первая строка составляет путь к Node.js из среды Codex, используя папку текущего пользователя без указания его имени в инструкции. Знак `&` во второй строке запускает программу по этому пути. `server.cjs` — файл инструкций для сервера. Если Node.js установлен отдельно и команда `node` доступна, достаточно `node server.cjs`.

Откройте в браузере `http://127.0.0.1:8000/`. Адрес `127.0.0.1` означает этот компьютер; 8000 — порт сервера. Окно PowerShell должно оставаться открытым. Для остановки нажмите в нём Ctrl + C. Для повторного запуска выполните ту же команду. Если порт занят предыдущим сервером, сначала остановите его. Для этого приложения npm и Python не нужны.

Сервер слушает только локальный адрес этого компьютера. Он не публикует сайт в интернете. После остановки страница может оставаться видимой в уже открытой вкладке, но сервер перестаёт отвечать на новые запросы.

История из страницы, открытой двойным щелчком, не переносится автоматически в HTTP-версию: браузер считает их разными адресами. Используйте один и тот же адрес `http://127.0.0.1:8000/` для доступа к одной истории.

## Как работает расчёт

Рост переводится из сантиметров в метры, затем вес делится на квадрат роста: `65 / (1.70 × 1.70) = 22.491349…`. Число на экране округлено до двух знаков, но категория определяется по исходному значению. Поэтому очень близко к границе округлённое число может совпадать с соседней границей.

Категории для взрослых: менее 18,5 — недостаточная масса; от 18,5 до менее 25 — нормальная; от 25 до менее 30 — избыточная; от 30 — ожирение по критерию ИМТ. Источник: [ВОЗ](https://www.who.int/data/nutrition/nlis/info/malnutrition-in-women).

Приложение принимает рост 100–250 см и вес 20–500 кг включительно. Это технические границы ввода, а не границы нормы. Принимаются точка и запятая для дробных чисел; пустые поля, буквы, отрицательные и выходящие за границы значения показывают ошибку. Изменение параметров убирает предыдущий результат до следующего расчёта.

Интерпретация предназначена для взрослых от 18 лет, не подходит детям и беременным. ИМТ не учитывает мышечную массу и состав тела, не является диагнозом и не заменяет индивидуальную оценку врача.

## Проверка расчётов (необязательно)

Если установлен Node.js, откройте PowerShell в этой папке: щёлкните по адресной строке Проводника, введите `powershell` и нажмите Enter. Выполните:

```powershell
node tests.js
```

Тесты используют только встроенные возможности Node.js. Они проверяют расчёт, валидацию, сохранение и восстановление истории, удаление, повреждённые данные, запрет записи и геометрию графика. Внешний вид проверяется отдельно в браузере.

## Как пользоваться новыми функциями

### Светлая и тёмная тема

Нажмите кнопку темы в верхней части страницы. Цвета фона, карточек, текста и графика плавно изменятся. При первом запуске приложение учитывает тему системы, после ручного выбора запоминает ваш вариант в этом браузере. При недоступном хранилище переключение работает до перезагрузки.

### История расчётов

Каждое нажатие «Рассчитать ИМТ» с правильными данными добавляет запись: дату и время, рост и вес. ИМТ и категория вычисляются из этих параметров по прежней формуле. Повторный расчёт тех же значений — отдельная запись. Самые новые записи находятся сверху; сохраняются последние 50. «Очистить поля» по-прежнему очищает только форму и текущий результат, история остаётся.

История сохраняется при обновлении страницы в том же браузере. В другом браузере, профиле или после переноса файла она может быть недоступна. Для страниц, открытых двойным щелчком через `file://`, поведение localStorage зависит от браузера. В приватном режиме данные могут исчезнуть после закрытия окон. При запрете сохранения приложение сообщает об этом, а расчёт продолжает работать. Данные доступны всем, кто пользуется этим профилем браузера.

### Интерактивный график

Каждая точка — один расчёт, слева старые, справа новые. По вертикали показан ИМТ, цветные полосы обозначают четыре прежние категории. Высота графика автоматически подстраивается под ваши значения, в том числе выходящие за пределы обычной шкалы 16–40. Интервалы между точками одинаковы: это последовательность расчётов, а не календарная шкала.

Наведите мышь, коснитесь точки или перейдите к ней клавишей Tab. Под графиком появятся точные данные. Enter и пробел тоже выбирают точку. Можно нажать на запись в списке — соответствующая точка выделится. На телефоне график прокручивается по горизонтали, чтобы точки оставались удобными для выбора. Ниже всегда доступен текстовый список всех данных.

График нарисован средствами SVG, встроенными в браузер: внешняя библиотека не требуется.

### Удаление

Кнопка «Удалить» у записи убирает только её. «Удалить историю» предлагает подтвердить удаление всех записей; «Отмена» сохраняет их. Удаляется только ключ истории этого приложения — тема и данные других сайтов не затрагиваются. Удаление истории не сбрасывает текущий результат в форме. Если браузер не разрешил удаление, приложение показывает ошибку и не сообщает об успехе.

### Телефон и анимации

На узком экране карточки размещаются друг под другом. Кнопки имеют удобную область нажатия, записи переносятся по ширине, график прокручивается внутри своей рамки. Добавлены плавное появление карточек и результата, изменение цветов темы и движение указателя шкалы. При включённом системном параметре уменьшения движения анимации отключаются.

## Ручная проверка в браузере

1. Рассчитайте 170 см / 65 кг: результат 22,49, нормальная масса, одна точка и запись в истории.
2. Рассчитайте 200 см / 100 кг: результат 25,00, избыточная масса, вторая точка.
3. Выберите первую точку мышью или клавиатурой: подробности должны соответствовать первому расчёту.
4. Включите тёмную тему и обновите страницу: тема и обе записи должны сохраниться, поля формы будут пустыми.
5. Введите буквы или оставьте поля пустыми: появится ошибка, новая запись не добавится.
6. Удалите одну запись, обновите страницу и проверьте, что осталась только другая.
7. Нажмите «Удалить историю», затем «Отмена»: история остаётся. Повторите с «Да, удалить всё»: список и график очищаются. Обновите страницу для проверки удаления.
8. Уменьшите ширину окна примерно до 360 пикселей: вся страница должна помещаться по ширине, а график — прокручиваться внутри рамки.

## Исправление контрастности тем

Раньше первое правило `:root` задавало тексту постоянный тёмный цвет, а ниже правило `html` пыталось заменить его цветом темы. Оба правила относятся к одному элементу, но `:root` имеет больший приоритет. Поэтому заголовки, логотип и подписи полей наследовали тёмный цвет даже на тёмном фоне.

Теперь в начале `styles.css` находятся две палитры CSS-переменных: светлая в `:root` и тёмная в `:root[data-theme="dark"]`. Переменная `--text` управляет основным текстом, `--muted` — пояснениями, `--surface` — карточками, `--field` — полями, `--primary` и `--on-primary` — фоном кнопки и надписью на ней. Заголовки, подписи и логотип явно используют `--text`. Цвет результата также выбирается через CSS-переменные: JavaScript больше не записывает цвет непосредственно в элемент.

Проверяются обычный текст, подсказки внутри полей, кнопки в обычном состоянии, при наведении и нажатии, ошибки, категории ИМТ, контуры полей, фокус и линия графика. Для текста применяется порог 4,5:1, для контуров и значимой графики — 3:1. Даже крупные заголовки и логотип проверяются с более строгим порогом 4,5:1. Отключённые кнопки оставлены приглушёнными: для неактивных элементов WCAG делает исключение. Декоративные границы карточек не являются границами полей ввода и остаются мягкими.

Команда `node tests.js` выполняет 57 функциональных проверок и 78 проверок контраста и регрессий. Минимальная контрастность среди проверенных пар текста: 4,95:1 в светлой и 6,21:1 в тёмной теме. Это расчёт по значениям CSS; он не заменяет визуальную проверку страницы в браузере и полный аудит доступности.

После изменения файлов обновите страницу сочетанием Ctrl + F5, переключите обе темы и проверьте заголовки, названия полей, кнопки и результат расчёта.
